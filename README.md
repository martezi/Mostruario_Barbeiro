# Bravo Barber Club — Site Demonstrativo

Landing page responsiva para uma barbearia masculina fictícia, desenvolvida como projeto de portfólio para demonstrar habilidades em desenvolvimento web e criação de sites comerciais.

## Funcionalidades
- Design moderno com identidade visual premium.
- Tabela de preços dos serviços.
- Galeria de cortes masculinos.
- Seções de apresentação, diferenciais e contato.
- Menu responsivo para dispositivos móveis.
- Animações de entrada e efeitos visuais.
- Integração configurável com WhatsApp e redes sociais.
- Mapa integrado com Google Maps.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Google Maps
- Imagens do Pexels

## Como executar
1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Para personalizar os contatos, edite o objeto `CONFIG` no final do arquivo JavaScript e substitua os links demonstrativos pelos links desejados.

## Observação
A Bravo Barber Club é uma marca fictícia criada exclusivamente para fins demonstrativos e apresentação de serviços de desenvolvimento web. Endereço, horários e preços são ilustrativos.
